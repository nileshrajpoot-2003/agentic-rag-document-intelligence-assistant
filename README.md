# Agentic RAG Document Intelligence Assistant

An agentic Retrieval-Augmented Generation system for intelligent
question answering over documents using LangGraph, LangChain,
semantic retrieval, conversational memory, and LLM-based reasoning.



## Key Features

- Multi-format document ingestion
- Document parsing and text chunking
- Semantic embedding generation
- FAISS-based vector retrieval
- LangGraph-based agentic workflow
- Context-aware document question answering
- Conversational memory
- Persistent chat sessions
- Real-time response streaming
- SQLite-based conversation persistence
- LangSmith tracing and observability
- Streamlit user interface
